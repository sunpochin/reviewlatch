# Changelog

## 0.2.0 — Composable pure API

- Export PR-state and thread-completeness inspection plus check-rollup classification and latest-result selection.
- Keep compatibility options explicit; the complete evaluator and CLI retain strict defaults.
- Reject ambiguous rules and non-boolean opt-ins; compare check timestamps chronologically and stop on unparseable evidence.
- Document immutable source vendoring and the caller's remaining evidence and authorization responsibilities.

## 0.1.0 — Initial extraction

- Configurable exact-head review and merge policy, including trusted reviewers and check App IDs.
- Paginated GitHub evidence collection and offline replay.
- Read-only status/thread commands, opt-in review-status publication, and head-locked guarded merge.
- English, Traditional Chinese, and Indonesian CLI messages.
- Synthetic regression tests, a composite GitHub Action, and a portable agent workflow.

Initial public implementation; npm distribution and automatic review orchestration are not included.
